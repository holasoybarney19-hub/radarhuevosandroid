RADAR DE HUEVOS — proyecto Android

Este proyecto genera una app Android básica para registrar apariciones e intervalos aproximados.
No incluye detección automática real: para eso se necesita una API o fuente de datos fiable del juego.
No usa hacks, no modifica Roblox y no solicita contraseñas.

Para compilar:
1. Instalar Android Studio en una computadora.
2. Abrir la carpeta RadarHuevos.
3. Esperar la sincronización de Gradle.
4. Build > Build APK(s).
5. El APK se genera en app/build/outputs/apk/debug/app-debug.apk.

El proyecto necesita conexión a internet durante la primera sincronización para descargar herramientas de compilación.
